# RayLauncher

**RayLauncher** is an unofficial modified version of [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2), featuring additional customization, visual enhancements, and tools designed to improve the Minecraft launcher experience on Android.

## Features

### RayLauncher Features

- **Liquid Glass UI** — Enhanced interface with Liquid Glass visual effects and translucent materials.
- **Custom Music Player** — Dedicated music player card with local music library support and external music sources, including Shizuku integration for supported access workflows.
- **Audio Visualizer** — Audio spectrum visualization through customizable visualizer cards.
- **Media Overlay** — Add image and video overlays to the launcher interface, with options to import and manage overlay media.
- **Custom Startup Animation** — Additional startup animation customization.
- **Customizable Card Grid** — Flexible card layout with drag-and-drop positioning, resizing, and an adjustment mode.
- **PanVK Execution Support** — Modified driver execution handling to support MediaTek Vulkan drivers, including PanVK. The driver itself is not bundled with RayLauncher.
- **Cape System** — Additional cape functionality adapted from ZalithLauncher2Plus.
- **Built-in Screen Recorder** — Integrated screen recording functionality for Minecraft gameplay, adapted from ZalithLauncher2Plus.

### Music Player

- Play music from a local library.
- Import audio files.
- Configure external music sources.
- Add and manage music player cards on the home screen.
- Shizuku integration for supported access operations.

### Audio Visualizer

- Display audio spectrum visualizations.
- Add and manage visualizer cards.
- Place visualizer cards within the customizable home screen grid.

### Media Overlay

- Import images and videos as overlays.
- Add and manage overlay cards.
- Remove imported overlay content when no longer needed.

### Card Grid

- Arrange cards through drag-and-drop.
- Resize cards.
- Use adjustment mode to customize card placement.
- Animated card layout interactions.

## Build

RayLauncher builds are provided through **GitHub Actions**.

1. Open the [Actions](https://github.com/KedaMC/RayLauncher/actions) tab.
2. Select a completed workflow run.
3. Download the available build artifact.

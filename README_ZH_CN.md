# RayLauncher

[English](README.md) | [简体中文](README_ZH_CN.md) | [繁體中文](README_ZH_TW.md)

## 关于

RayLauncher 是基于 [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) 的非官方修改版，目标是尽可能降低启动器的资源占用。优化方向包括减小 APK 体积，并在可行的情况下提升 Minecraft 的运行性能。

## 功能

- **Liquid Glass** — 采用 Liquid Glass 视觉效果的现代化界面。
- **PanVK 执行支持** — 修改驱动执行机制，使启动器能够运行包括 PanVK 在内的 MediaTek Vulkan 驱动。RayLauncher 不包含 PanVK 驱动本身。
- **披风系统** — 移植自 [ZalithLauncher2Plus](https://github.com/Star1xr/ZalithLauncher2Plus) 的披风功能。
- **内置录屏工具** — 集成 Minecraft 游戏画面录制功能，移植自 ZalithLauncher2Plus。

# RayLauncher

[English](README.md) | [简体中文](README_ZH_CN.md) | [繁體中文](README_ZH_TW.md)

**面向 Android 的非官方 Minecraft: Java Edition 启动器修改版。**

RayLauncher 是基于 [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) 的社区维护修改版，主要提供自定义启动器体验与界面改进。

> **非官方修改版**
>
> RayLauncher 是独立项目，与原 Zalith Launcher 开发者、Mojang Studios 或 Microsoft 没有隶属关系，也未获得其认可或支持。

## 功能

- 自定义启动器界面。
- [`feature/liquid-glass` 分支](https://github.com/KedaMC/RayLauncher/tree/feature/liquid-glass) 正在开发 Liquid Glass 风格的视觉效果。不同分支中的功能可能有所不同，且后续可能调整。
